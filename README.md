# Geolocation

A simple HTML/JavaScript tool to get your device's geographic coordinates using the browser's Geolocation API.

## How to use

1. Open `index.html` in your browser
2. Click the "Get location" button
3. Allow location access when prompted
4. Your latitude and longitude will be displayed on the page

## Features

- Clean, minimalist interface
- High accuracy positioning
- Handles browser errors gracefully
- Responsive design
- Accessible with ARIA labels

## Browser support

Works on any modern browser with geolocation support. If your browser doesn't support geolocation, you'll see a message letting you know.
